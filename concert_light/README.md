# Concert Light — свет через uDMX, синхронно с Concert DAW

> **Бета-версия.** Программа новая и ещё проверяется на реальных концертах. Перед выступлением
> обязательно прогоните шоу на репетиции. Нашли ошибку — Настройки → Обновления и отзывы →
> «Сообщить об ошибке» или вкладка **Issues** на GitHub.

Третья программа комплекта. Пульт управления светом в духе **Sunlite Suite** для недорогого
USB-DMX интерфейса **uDMX** (в том числе китайских клонов, USB ID `16C0:05DC`).
Concert DAW — **мастер**: нажали PLAY в DAW — свет идёт по таймлайну песни; пауза, перемотка,
стоп и смена трека повторяются автоматически.

Можно ставить на компьютер со звуком (рядом с Concert DAW) или на отдельный — в той же сети.

## Установка (Windows 10/11)

1. Скопируйте папку `concert_light` на компьютер (например, в `C:\Concert Light`).
2. Запустите **install.bat** — он сам поставит Python (если нужно) и библиотеки
   (PySide6, pyusb, libusb). Нужен интернет, ~300 МБ.
3. **Драйвер uDMX** (один раз). Если install.bat написал «uDMX не найден»:
   скачайте [Zadig](https://zadig.akeo.ie/) → меню **Options → List All Devices** →
   выберите **uDMX** (USB ID 16C0 05DC) → драйвер **libusb-win32** → **Install Driver**.
   Переподключите uDMX. Подсказка есть и в программе: **Настройки → uDMX**.
4. Запуск — ярлык **Concert Light** на рабочем столе или `start.bat`.
   Если программа не открывается — `start_debug.bat` покажет ошибку.

Справа вверху точка: зелёная — uDMX подключён. Выдернули кабель — программа сама
переподключится, когда он вернётся.

## Как работать

| Вкладка | Что делает |
|---|---|
| **Патч** | Приборы и DMX-адреса. **«Свой прибор (каналы вручную)»** — назначить функцию каждому каналу; ползунок «Проверка» сразу двигает этот канал на приборе. |
| **Программер** | Выбрать приборы → диммер, цвет (пресеты), pan/tilt (XY-пэд), гобо… → «Записать» сцену. |
| **Сцены** | Кнопки-пресеты: щелчок — включить с фейдом (кнопка загорается цветом сцены), ещё щелчок — выключить (гаснет). Сцена главнее программера. |
| **Чейзы** | Сцены по шагам: длина шага, фейд, TAP-темп. |
| **Эффекты** | Круг (pan/tilt), Волна (яркость), Радуга (RGB), разброс фазы по приборам. Идут поверх сцен. |
| **Таймлайн** | Кьюшки по времени песни: сцена, старт/стоп чейза, эффект вкл/выкл, сброс, blackout. |

**Мастер** и **BLACKOUT** — в панели сверху. **Сброс всего** — погасить всё и остановить эффекты.

Быстрая запись таймлайна: включите **«● Запись кьюшек с пульта»**, запустите песню и нажимайте
сцены, чейзы, эффекты — кьюшки встанут в нужные моменты. Потом время правится в таблице.

## Подключение к Concert DAW

* Работает так же, как у Concert Video, — через тот же сервер синхронизации.
  В Concert DAW: **Настройки → Видео → «Разрешить подключение»**.
* Concert Light при первом запуске **сам находит** Concert DAW в сети и подключается.
  Вручную: **Настройки → Concert DAW** → «Найти в сети» или ввести IP
  (`127.0.0.1`, если DAW на этом же компьютере).
* **Таймлайн → «Из Concert DAW…»** — создать песни для треков DAW (с привязкой к треку:
  переименование трека в DAW связь не сломает). Песни, созданные вручную, связываются
  по совпадению названия.
* **Таймлайн → источник «Concert DAW»** — песня выбирается сама по треку, который играет DAW.
  Перемотка в DAW восстанавливает правильный свет на этом месте песни.
* Без DAW: источник «Своё аудио / таймер» — выберите аудиофайл песни и программируйте свет дома.
* Порты: TCP 47810 (данные), UDP 47811 (поиск). При первом запуске Windows спросит
  разрешение для сети — нажмите **«Разрешить»**.

## Приборы

Готовые типы — **общие (Generic)**: диммер, RGB/RGBW PAR, головы spot и wash, сканер.
У китайских приборов порядок каналов бывает разный. Тогда: Патч → **«Свой прибор (каналы вручную)»**
(или выберите прибор → «Изменить каналы прибора»). Выставьте на приборе тот же адрес и режим,
двигайте «Проверку» у каждого канала — увидите, что он делает, — и выберите ему функцию.
Каналы, которым функция не нужна, оставьте «без функции»: они всё равно будут в программере
как «Канал N». Свои типы хранятся в `%APPDATA%\ConcertLight\fixtures`
и не пропадают при обновлении.

## Где что хранится

* Шоу — файлы `.clshow` (по умолчанию `Документы\Concert Light`). Последнее шоу открывается само.
* Настройки и журнал ошибок — `%APPDATA%\ConcertLight`.

## Обновление

Программа сама раз в сутки проверяет новую версию на GitHub: внизу окна появится жёлтая кнопка
**«⬆ Обновление»** — клик, «Обновить сейчас». Обновление перезапускает программу, поэтому
во время концерта оно не начнётся, пока горит свет. Вручную — **update.bat** (программа закрыта).

## Идеи и ошибки

**Настройки → Обновления и отзывы** → «Предложить идею» / «Сообщить об ошибке».

## Удаление

**uninstall.bat** в папке программы. Ваши шоу не удаляются.

## Для разработки

```
           timeline.py, output.py (вывод с переподключением), appdata.py (настройки)
ui/        окна и вкладки (PySide6)
fixtures/  библиотека приборов (JSON)
sync_client.py, updater.py, gui_update.py, feedback.py, gui_feedback.py — общие с Concert Video
tests/test_core.py — тесты без устройства и без Qt: python tests/test_core.py
```
