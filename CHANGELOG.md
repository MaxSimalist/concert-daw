# История версий

## 0.9.2 (бета) — Concert Light: сцены включаются, ручной патч каналов

* Сцена не включалась, если в программере оставались значения (после «В программер» или записи
  без очистки) — они перекрывали сцену. Теперь сцена главнее: то, что она задаёт, убирается
  из программера.
* Сцена получалась тёмной, если при записи не трогали диммер. Теперь по умолчанию записываются
  все каналы выбранных приборов — так, как они сейчас выглядят (галочка «все каналы приборов»);
  если диммер всё-таки 0 — программа предупредит.
* Повторный щелчок по включённой сцене — выключить её.
* Ручной патч: Патч → «Свой прибор (каналы вручную)» и «Изменить каналы прибора» — каждому
  DMX-каналу своя функция и значение по умолчанию; ползунок «Проверка» сразу шлёт значение
  на канал uDMX, чтобы найти, какой канал что делает. Можно начать с готового типа.

## 0.9.1 (бета) — Concert Light: свет через uDMX

* Новая программа комплекта (бета-версия) — пульт света для USB-DMX интерфейса uDMX
  (и китайских клонов, USB ID 16C0:05DC).
* Патч приборов с библиотекой типов (диммер, RGB/RGBW PAR, головы spot/wash, сканер) и своими
  типами; программер с цветовыми пресетами и XY-пэдом pan/tilt; сцены с фейдом; чейзы с TAP-темпом;
  эффекты «круг», «волна», «радуга».
* Таймлайн света для каждой песни; запись кьюшек прямо с пульта во время песни.
* Синхронно с Concert DAW через тот же сервер, что и Concert Video: сам находит DAW в сети,
  сам выбирает песню по играющему треку, после перемотки восстанавливает свет.
* Устойчивая связь с uDMX: одиночные сбои USB не рвут связь, переподключение само,
  диагностика и журнал связи в Настройки → uDMX.
* Установка, обновление с GitHub, отзывы и удаление — как в Concert DAW и Concert Video.

## 1.2.4 — Concert DAW: таймлайн «по размеру» по умолчанию

* Таймлайн сразу показывает весь трек целиком — при выборе трека, записи и при изменении
  размера окна. Если поменять масштаб ползунком, он сохраняется до выбора следующего трека;
  кнопка «по размеру» снова включает автоподгонку.

## 1.2.3 — Concert DAW: увеличение волны в редакторе трека

* В редакторе трека волну можно увеличивать для точной обрезки: колесо мыши — увеличить/уменьшить
  вокруг курсора (до четверти секунды на всю ширину), Shift+колесо или полоса прокрутки —
  листать, зажатое колёсико — тащить, двойной клик — весь трек.
* Кнопки под волной: «−», «+», «Весь трек», «◀ Начало обрезки», «Конец обрезки ▶» — сразу
  увеличивают вокруг нужного маркера.
* Сверху волны — шкала времени (при сильном увеличении — до сотых секунды), волна стала
  подробнее (5 мс на столбик).

## 1.2.2 — Concert DAW: перегруз без искажений

* Раньше всё громче 0 dBFS (фейдер выше нуля, нормализация громкости, эквалайзер, смена тона,
  несколько дорожек на одном выходе) жёстко срезалось — это слышно как хрип и треск.
  Теперь на каждой дорожке и на выходах стоит защитный ограничитель: при перегрузе громкость
  плавно убирается ровно настолько, насколько нужно, и плавно возвращается. Искажения
  синуса при перегрузе на 6 dB: было 21.9 %, стало 0.5 %.
* Пока сигнал тише −1 dBFS, ограничитель ничего не делает — звук бит-в-бит как в файле.
* Лампа перегруза на индикаторе дорожки по-прежнему загорается: значит, дорожку перегнали
  и работает ограничитель — лучше опустить фейдер.

## 1.2.1 — Concert DAW: плавный масштаб таймлайна

* Ползунок масштаба таймлайна стал плавным: каждый шаг меняет масштаб в одно и то же число раз
  (раньше у левого края он прыгал в разы от малейшего движения). Колесо мыши над ползунком —
  шаг ~10 %. Масштаб можно уменьшить сильнее — целиком помещаются треки до 10+ минут.

## 1.2.0 — Concert DAW: удалённые файлы и точная тональность

* Если файлы трека удалены с диска (или переименованы, или флешка отключена), трек в списке
  отмечается: красным и зачёркнутым — «⚠ файл удалён», жёлтым — «⚠ нет 1 из 5» (части дорожек).
  Программа проверяет это сама каждые пару секунд. Правый клик: **«Найти файлы…»** (указать
  папку, куда их перенесли — найдутся по имени), «Убрать дорожки без файлов», «Убрать из плейлиста
  все треки без файлов». Трек без файлов не загружается — вместо тишины понятное сообщение.
* **Тональность определяется точнее**: барабаны не учитываются, берутся только тональные пики
  спектра, учитывается строй (если фонограмма не на A=440), сравнение сразу с тремя наборами
  эталонов, а мажор/параллельный минор (C ↔ Am) различаются по первому и последнему аккорду и
  последней басовой ноте. На тестовом наборе из 96 фонограмм точность выросла с 62 % до 97 %.
  Тональности, найденные прежним способом, пересчитываются сами в фоне (указанные вручную — нет).

## 1.1.0 — обновления и отзывы

* Настройки → **Обновления и отзывы** (в обеих программах): установленная версия, «Проверить
  сейчас», включить/выключить автоматическую проверку при запуске.
* **Предложить идею / Сообщить об ошибке**: человек пишет текст, видит весь отчёт и сам
  отправляет его через GitHub (или копирует). По желанию добавляются версия программы,
  Windows и последние ошибки из журнала; имя пользователя, компьютера и пути убираются.
  Программа ничего не отправляет сама и не собирает данные в фоне.
* В окне ошибки — кнопка **«Сообщить об ошибке…»** с уже готовым отчётом.
* Обновление работает и без оформленного релиза на GitHub.

## 1.0.0 — первая версия

**Concert DAW** — концертный плеер мультитреков для Behringer X32 (X-USB / X-LIVE, ASIO):
плейлисты, роутинг дорожек на выходы пульта, PLAY / PAUSE / STOP, Auto-cue, редактор трека
(тон, темп, обрезка), тональность и темп, метроном и отсчёт, маркеры и петли, LUFS,
таймлайн, запись с пульта с выбором каналов, фейдеры записи с EQ и многополосным компрессором,
VST3, синхронизация фейдеров и FX-темпа пульта по сети, MIDI-педаль, мастер-время для Concert Video.

**Concert Video** — видео на экраны сцены по образцу OBS Studio: сцены и источники, студийный
режим, переходы, проекторы, микшер с индикаторами, синхронизация видео с треками Concert DAW,
расписание по времени, Play/Пауза и перемотка эфира, запись и трансляция.

Обе программы: install.bat / uninstall.bat / update.bat, обновление из GitHub прямо из программы.
