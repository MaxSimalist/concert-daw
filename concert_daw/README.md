# Concert DAW для Behringer X32

Концертный плеер треков и мультитреков: плейлисты, роутинг дорожек на 32 USB-выхода
X32 (X-USB / X-LIVE) по ASIO, работа без пульта, VST3-инсерты, таймлайн, запись с пульта,
тональность, темп и метроном.

## Установка на новый компьютер (Windows 10/11)

1. Распакуйте архив в постоянную папку, например `C:\ConcertDAW`.
2. Запустите **`install.bat`** (двойной клик). Он сам:
   * найдёт Python 3.10–3.13, а если его нет — установит Python 3.12 через winget;
   * создаст окружение программы `.venv` внутри её папки (системный Python не трогается);
   * установит все библиотеки (~300 МБ, нужен интернет) и проверит их;
   * проверит, виден ли ASIO-драйвер пульта X32;
   * создаст ярлык **Concert DAW** на рабочем столе.
3. Драйвер пульта (**X-USB ASIO** или **X-LIVE**) ставится отдельно — с behringer.com
   (страница X32 → Downloads). Без пульта программа тоже работает через звуковую карту.

Запуск: ярлык на рабочем столе или **`start.bat`**.
Если программа не открывается — **`start_debug.bat`** покажет ошибку в окне.
Ошибки также пишутся в `%APPDATA%\ConcertDAW\error.log`.

Обновление: замените файлы программы новыми (папку `.venv` оставьте) и запустите
`install.bat` ещё раз — он доставит новые библиотеки. Плейлисты и настройки сохраняются.

## Окно

Все зоны (транспорт, плейлисты, список треков, таймлайн, микшер, фейдеры пульта) разделены
границами — тяните их мышью, размеры запоминаются. Окно подстраивается под экран ноутбука:
длинные названия сокращаются с «…» (полный текст — в подсказке), ряды кнопок переносятся на
следующую строку, а если окно совсем узкое — у транспорта появляется полоса прокрутки.
Зоны «заклинили» или стали неудобными — ⚙ Настройки → Интерфейс → «Сбросить расположение зон».

## Треки

* **+ Трек** — выбрать аудиофайлы (WAV, MP3, FLAC, AIFF). Каждый файл — отдельный трек.
  Название трека — имя файла без расширения («Кукушка (минус).mp3» → «Кукушка (минус)»).
  В Настройки → Плейлист можно переключить на теги файла («Название» из MP3 ID3).
  Уже добавленные треки: правый клик → «Название из имени файла» (или сразу для всего плейлиста).
* **+ Мультитрек** — папка с дорожками одного трека (Клик, Гайд, Бас, Плейбек L/R…).
* **+ Сет** — папка, где каждая подпапка — трек.
* Перетаскивание из Проводника: файлы → треки; папка с дорожками одной длины → мультитрек;
  папка с файлами разной длины (альбом) → отдельные треки.
* Внутри списка — перетаскиванием меняется порядок. Двойной клик — сразу играть (во время игры текущий трек плавно гаснет), правый клик — меню («Загрузить» — встать на трек без запуска).

## Таймлайн (над фейдерами, ☰ / Ctrl+T — показать/скрыть)

* Волны дорожек трека и каналов записи на общей шкале времени, курсор движется при игре.
* Клик — перемотка. Протянуть мышью по дорожке — выделить участок.
* **✂** — обрезать дорожку по выделению (до и после — тишина, синхронность сохраняется), **↺** — снять,
  **🗑** — убрать дорожку из трека (файл на диске остаётся).
* **＋ Мультитрек** — добавить в трек дорожки другого трека из плейлистов или файлы.
* **Запись:** выбор записи в списке (новые сверху), **Удалить запись** — целиком в корзину.
  У каждого канала: **💾** сохранить на компьютер (выделение или целиком), **➕** добавить в трек
  новой дорожкой, **🗑** удалить канал. Запись встаёт точно под трек — сохраняется позиция
  трека при старте и задержка ASIO.

## Транспорт

* **PLAY / PAUSE / STOP**: PAUSE останавливает трек и запоминает место — повторное нажатие (или PLAY) продолжает с него; STOP останавливает и возвращает в начало трека.
* **Пробел** — играть / пауза, **Esc** — стоп и в начало, **PgDown/PgUp** — следующий/предыдущий.
* MIDI-педаль: действия «Play / Пауза», «Пауза / продолжить», «Stop (в начало)».
* Клик по полосе прогресса или **← / →** — перемотка (и во время игры).
* Выбор другого трека во время игры — текущий плавно гаснет, выбранный играет
  (или встаёт на начало — ⚙ Настройки → Плейлист).
* **Каналы для записи:** правый клик по кнопке REC (или Настройки → Запись → «Выбрать каналы…») — отметьте нужные входы из 32 и подпишите их. Файлы называются по имени канала (`Ch05 Вокал.wav`), на таймлайне видны те же имена. Кнопка «Имена с пульта» берёт названия каналов X32. При первом нажатии REC окно выбора каналов откроется само.
* **● REC / Ctrl+R** — запись с пульта, **M** — метроном, **C** — отсчёт, **L** — петля,
  **1–9** — маркеры, **Ctrl+E** — редактор трека, **Ctrl+,** — настройки.

## Секундомер концерта (⏱ над временем трека)

* Запускается сам, когда начинает звучать **первый трек плейлиста** (после отсчёта 1-2-3-4) —
  «время пошло». Пауза и стоп между треками его не останавливают.
* Клик по ⏱: «Запустить сейчас», «Сбросить», «Запускать с текущего трека» (выберите трек, с
  которого начинается концерт), «Запускать только вручную».
* Если программу перезапустили посреди концерта, секундомер продолжит с того же места.
* То же время показывают Concert Video, Concert Light и табло Concert Stage.

## Тональность, темп, метроном

* Определяются автоматически в фоне и показываются рядом с названием: `Am • 120 BPM`.
  При сдвиге тона — `Am → Bm`. Поправить: правый клик по треку → Тональность;
  темп — правый клик по кнопке ♩ или поле «исходный темп» в редакторе трека.
* **Метроном**: на паузе — в темпе трека, во время игры — точно по его долям.
  Выход, громкость, акцент — ⚙ Настройки → Звук.

## Редактор трека (✎)

Обрезка по волне, fade in/out, скорость 50–200 % без смены тона, тональность ±12 полутонов
без смены темпа (клик и гайд не транспонируются), действие в конце трека
(стоп / играть следующий с паузой), экспорт обработанной версии в WAV.

## Микшер

Дорожки можно переставлять мышью — потяните за название. Стрип дорожки: выход X32,
инсерт VST3, Mute/Solo, фейдер (двойной клик или нажатие колёсиком —
0 dB; возле нуля фейдер «прилипает», жёлтая риска — 0 dB),
индикатор со шкалой dB — у стерео-дорожки два столбика (L/R), у моно один.
Правый клик по стрипу — переименовать, убрать дорожку, транспонирование.
На фейдерах пульта — индикаторы уровня сигнала с самого пульта (у MAIN LR — L и R; у DCA
уровень считается по каналам и шинам, назначенным в эту DCA — программа узнаёт состав DCA с пульта). Длинные названия треков в списке сокращаются с «…»,
а длительность, тональность и темп справа остаются видны; полное название — в подсказке.

## Работа без пульта

Если X32 не найден — звук идёт через звуковую карту компьютера, дорожки сводятся в стерео.
Назначенные выходы Out 1–32 сохраняются и заработают с пультом.

## Запись с пульта

Записываются входы карты X-USB (что туда идёт — Routing → Card Out на пульте).
Настройки → Запись: папка, каналы (окно выбора), формат WAV, файл на канал,
запуск вручную или с каждым PLAY. 32 канала 24 бит — около 16 ГБ в час, пишите на SSD.

**После записи — фейдер на пульт.** Когда запись остановлена, каждый записанный канал
появляется в микшере трека отдельной дорожкой «Запись: 5 Вокал» — с фейдером, выходом
Out N на пульт (первый свободный) и уже включёнными эквалайзером и компрессором для голоса.
Каналы выровнены под трек с учётом задержки ASIO, поэтому голос звучит точно в такт.
REC можно нажать и раньше PLAY — привязка к треку всё равно сохранится.
Если трек ещё играет, фейдеры появятся после остановки. Новый дубль того же канала
заменяет запись на фейдере, а выход, громкость, EQ и компрессор остаются как были.
Выключить: Настройки → Запись → «После записи добавлять каналы в трек».

## Плагины на дорожке: CD Pro EQ и CD Multiband (кнопки EQ и COMP)

Встроенные плагины есть на каждой дорожке. Клик по кнопке открывает окно плагина
(как у студийных: FabFilter Pro-Q / Pro-MB, Waves C4), правый клик — включить/выключить.
Изменения слышны сразу, во время игры. Покрутили регулятор — плагин включается сам.

**Крутилки:** тянуть мышью вверх-вниз (с Shift — точно), колесо мыши, двойной клик —
значение по умолчанию, правый клик — ввести число.

**Шапка окна:** кнопка питания (вкл/выкл), сравнение **A/B** (две версии настроек,
переключайтесь и слушайте; «A→B» копирует текущую), пресеты.

* **CD Pro EQ** — большой график с анализатором спектра (серый — до обработки, зелёный — после)
  и кривой эквалайзера. Точки полос тянутся мышью (влево-вправо — частота, вверх-вниз — усиление),
  колесо над точкой — ширина Q, двойной клик — 0 dB, по точке HP — вкл/выкл среза низа.
  Внизу: LOW CUT (24 dB/окт), 4 полосы с формой (полка НЧ / колокол / полка ВЧ) и крутилками
  Частота, Усиление, Q; выходная громкость и индикаторы IN/OUT.
  Пресеты: «Вокал», «Убрать гул и бубнение», «Речь», «Хор», «Баян», «Акустическая гитара».
* **CD Multiband** — 3 полосы (НЧ / СЧ / ВЧ). На графике — спектр, границы полос (тянутся мышью)
  и ослабление каждой полосы в реальном времени. У полосы: СЖАТИЕ (вкл), S — послушать полосу
  отдельно, крутилки Порог, Степень, Усиление, Атака, Восстановление и индикатор GR.
  ОБЩЕЕ: границы полос, Mix (параллельная компрессия), Выход, индикаторы IN/OUT.
  Пресеты: «Вокал — мягко / плотно», «Де-эссер», «Речь — выровнять», «Мастер — склеить».

Порядок обработки: EQ → компрессор → VST-инсерт → фейдер. Нужна библиотека scipy —
она ставится через install.bat. Если её нет, окно плагина всё равно откроется, а вверху будет жёлтая плашка с кнопкой «Установить» — библиотека установится прямо из программы, без перезапуска.

## Отсчёт перед стартом (кнопка «1-2-3-4», клавиша C)

Включённый отсчёт даёт 1–4 такта метронома в темпе трека, затем трек стартует ровно на
следующей доле (стык точный до сэмпла, учитывается первая доля трека). Выключен — трек
стартует сразу. Число тактов и размер — ⚙ Настройки → Звук. STOP во время отсчёта отменяет старт.

## Маркеры и петли

* **＋ Маркер** на таймлайне — флажок в позиции курсора (Интро, Куплет, Припев…).
* Переход: клик по флажку на линейке, клавиши **1–9**, **Shift+← / Shift+→**.
  Правый клик по флажку — перейти, перенести, переименовать, удалить.
* Над временем показывается текущая часть трека (▸ 3. Припев).
* **🔁 Петля** (клавиша **L**): повторяет выделенный участок; без выделения — часть между
  маркерами вокруг курсора (например, весь припев).

## Выравнивание громкости (LUFS)

⚙ Настройки → Плейлист: все треки приводятся к одной громкости (по умолчанию −16 LUFS,
стандарт ITU-R BS.1770). Измеряется в фоне по музыкальным дорожкам; клик и гайд не меняются.
Тихие треки поднимаются не больше заданного предела и никогда не выше 0 dBFS по пику.
Трек можно исключить в его редакторе.

## Пульт X32 по сети (OSC)

**Подключение:** кнопка **🔌 Подключить пульт X32** в панели фейдеров пульта (или ⚙ Настройки →
Пульт X32 → «🔍 Найти пульт»). Программа сама ищет пульт в сети и показывает его IP —
остаётся нажать «Подключить». Можно ввести IP вручную (на пульте: Setup → Network).
Компьютер и пульт — в одной сети: кабель в разъём Remote (Ethernet) пульта, напрямую или через роутер.

**Фейдеры пульта в программе** (справа от дорожек, граница двигается мышью):
* по умолчанию — мастер **MAIN LR**; **＋** добавляет любые: каналы 1–32, Aux In, FX Return,
  шины, матрицы, DCA, M/C, мастер (в меню видны названия каналов с пульта);
  **×** — убрать фейдер из программы, включая мастер (на пульте ничего не меняется);
* **порядок меняется мышью** — потяните фейдер за название и отпустите на новом месте;
* синхронизация в обе стороны: двигаете на пульте — двигается в программе, и наоборот;
  кнопка **M** — mute на пульте;
* при запуске программа считывает с пульта положения фейдеров, mute и названия;
  то же — после восстановления связи и по кнопке **⟳**.

**Сцены и сниппеты:** в редакторе трека (✎) — номер сцены и/или сниппета пульта;
переключаются при выборе трека или при PLAY. Сцена меняет всё, что не защищено Scene Safes.

Если связи нет при правильном IP — разрешите Python в «Брандмауэр Защитника Windows →
Разрешить взаимодействие с приложением».

## MIDI-педаль / контроллер

`pip install mido python-rtmidi`. ⚙ Настройки → MIDI: выберите вход, нажмите «Обучить» у
действия и нажмите педаль. Действия: Play/Stop, Play, Stop, следующий/предыдущий трек,
следующий/предыдущий маркер, петля, метроном, отсчёт, запись. Для CC-педалей с фиксацией —
галочка «срабатывать на любое изменение».

## Тишина в начале и в конце трека

Программа сама проверяет треки (в фоне, когда ничего не играет; выбранный трек — первым).
Если в начале больше 0,5 с тишины или в конце больше 1 с — над дорожками появляется подсказка
**«🔇 В треке тишина: в начале 3,2 с…»** с кнопками:
* **✂ Обрезать** — убрать тишину (исходные файлы не меняются; оставляется 50 мс до первого звука
  и 250 мс после последнего, чтобы не срезать атаку и хвост реверберации, плюс короткие фейды);
* **Настроить…** — открыть редактор трека: кнопка **✂ Тишина** ставит маркеры начала/конца по
  найденной тишине, дальше их можно подвинуть мышью на волне;
* **Не надо** — больше не предлагать для этого трека.

Подсказка не всплывает окном и не мешает работе во время концерта. Правый клик по треку →
«Обрезать тишину во всех треках плейлиста» — сразу для всего сета. Вернуть — ✎ Редактор →
«Без обрезки». Выключить подсказки — ⚙ Настройки → Плейлист. Тишина — это когда молчат все
дорожки сразу: если клик начинается раньше музыки, его щелчки не срежутся.

## Темп эффектов пульта (FX)

⚙ Настройки → Пульт X32 → «Темп эффектов пульта».
* **Авто** (включено по умолчанию): при выборе трека программа сама проверяет FX 1–4 и всем
  **Stereo Delay** выставляет время под темп трека с выбранной долей (по умолчанию 1/4).
  Остальные эффекты не трогаются и не упоминаются.
* Для отдельного слота можно задать свою долю (1/8, 1/8 с точкой, триоли…) — она важнее авто.
* Время считается с учётом скорости из редактора: 120 BPM, 1/4 → 500 мс.
* Время отправляется через 0,3 с после сцены трека — если сцена меняет эффекты, время не затрётся.
* Результат проверяется: программа считывает с пульта значение в мс и показывает
  «FX2 Stereo Delay: 500 мс ✔». Если пульт кодирует время по другой шкале — программа сама это
  заметит, исправит и запомнит.
* Множители Factor L/R на самом пульте продолжают работать от этого времени.
* Эффекты без времени задержки (реверберации, хорус и т.п.) не трогаются — в строке состояния
  будет сказано, что слот пропущен.
* Если темп трека определён неверно — правый клик по кнопке ♩ → задать вручную; FX обновятся.

## Видео на экранах (Concert Video)

Concert DAW — мастер времени для второй программы **Concert Video** (папка `concert_video`,
ставится на компьютер с проекторами). Видео-программа подключается по сети и запускает
видео синхронно с треком: PLAY, пауза, перемотка, отсчёт, стоп и смена трека повторяются
на экранах. Настройки → **Видео**: разрешить подключение (включено), порт (47810),
IP этого компьютера и кто подключён. В строке состояния — «Видео: 1 подкл.».
При первом запуске Windows спросит разрешение для сети — нажмите «Разрешить».
Подробно — в `concert_video/README.md`.

## Производительность

Смена темпа и тона считается в отдельных процессах — параллельно на нескольких ядрах и не
мешая звуку и интерфейсу. Процессы поднимаются через 3 с после запуска программы. Если нажать
PLAY, пока трек ещё готовится, — он запустится сам, как только будет готов. Результат кэшируется:
повторно трек с тем же тоном открывается мгновенно. После правки в редакторе расчёт начинается
сразу, даже если трек ещё не выбран.

## Ограничения

* Python — не C++: тяжёлые действия во время песни могут дать щелчок. Следите за счётчиком
  «выпадений» в строке состояния; если растёт — буфер 512.
* VST: только VST3, задержка плагинов не компенсируется.
* Перед концертом прогоните весь сет на той же машине.

## Оформление

Тема «Graphite»: тёмный графитовый фон, плоские кнопки, один акцентный цвет (мятно-зелёный) для всего включённого, жёлтый — внимание, красный — запись и ошибки. Все значки нарисованы программой в одном стиле (не зависят от шрифтов Windows). Цвета темы — в файле `style.py`.

## Удаление

**uninstall.bat** в папке программы: закрывает программу, удаляет ярлык на рабочем столе и
окружение Python (.venv). Затем спрашивает, удалить ли настройки (`%APPDATA%\ConcertDAW`) и саму
папку программы. Ваши аудио- и видеофайлы, записи и сохранённые проекты в других папках не трогаются.
